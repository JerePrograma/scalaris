# Tienda de hardware retirada

Archivada el 28/10/2026 por decisión del usuario: la web de Scalaris ofrece productos y desarrollo de software. Esta carpeta conserva la tienda, las fotos y el catálogo histórico fuera de `public/`, que es el único directorio publicado por Cloudflare Pages.

No copiar esta carpeta a `public/` ni incluirla en el despliegue. Los enlaces antiguos `/tienda` y `/tienda/*` redirigen a `/productos/`.

El importador de proveedores y el exportador de referencias escriben aquí por defecto. El cálculo de precios admite `--apply-archive` para actualizar exclusivamente este catálogo histórico; `--apply-public` está retirado y se rechaza. Costos, credenciales y configuración comercial privada conservan sus ubicaciones fuera del sitio.

Las pruebas de los modelos históricos se mantienen para comprobar las herramientas internas. Este archivo no es una vista previa autónoma: sus enlaces de navegación y recursos compartidos conservan su procedencia anterior.

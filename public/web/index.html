Antes de comenzar

Lo que conviene tener claro.

Revisamos tu material y confirmamos el alcance antes de iniciar el trabajo.

¿Qué contenido tengo que entregar?

Logo disponible, información de tu negocio, fotografías con permiso de uso y datos de contacto. En lanzamiento sumamos hasta 60 minutos para ayudarte a redactar o mejorar textos y ordenar el material. Fotografía, identidad de marca y producción audiovisual se cotizan aparte. Acordamos el plazo con el material completo.

¿Qué cambios incluye cada plan?

Origen: Mantenimiento técnico. Los cambios de contenido posteriores al alta se cotizan aparte.

Web de hasta 5 páginas: El lote mensual cubre textos, fotos y datos sobre la estructura existente. No es acumulable ni incluye nuevas páginas o funciones.

¿Cómo funcionan el dominio y el correo?

Con anual anticipado de lanzamiento incluimos el primer año de un .com.ar disponible a tu nombre. Disponibilidad y vinculación se confirman antes de contratar. La renovación posterior queda a tu cargo. Con mensual, el dominio se abona por separado.

Acceso web con el plan gratuito de Zoho, disponible sólo para organizaciones elegibles según la región. No incluye IMAP/POP, migración de correo ni licencias pagas. La disponibilidad se confirma antes de contratar.

¿Cómo se paga y se renueva?

Mensual: precio inicial garantizado por tres meses; luego revisión trimestral con aviso de treinta días. Doce meses desde la activación acordada. Renovación a la tarifa informada con treinta días de anticipación, sin repetir la puesta en marcha del mismo alcance. El dominio se renueva a cargo del cliente.

El anual de lanzamiento se paga por adelantado: doce meses con 10% menos en el abono; Origen tiene el alta 100% bonificada y Web de cinco páginas, 50%. En mensual, el alta completa se divide en tres cuotas sin recargo. El saldo del trabajo inicial ante una baja se informa por escrito antes del primer pago. La consulta permite revisar el desglose.

¿Y si necesito más funciones?

Nuevas páginas, otro diseño, integraciones o funciones especiales tienen un presupuesto específico. Estos planes presentan contenido institucional; una tienda o un panel de autogestión se revisan como otro alcance.
